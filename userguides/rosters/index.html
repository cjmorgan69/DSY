Crew Shift Roster

Quick guide for roster users

User Guide
Welcome. Use this guide to book shifts, check roster coverage, view your bookings, share team messages, and manage changes to submitted hard-copy rosters.
Getting started

Enter your details

  1. Enter your name in the page header.
  2. Select your clinical level.

Available clinical levels are:

  • PARA
  • AO
  • AR
  • AA
  • REC — Recruit / observer
Your name and clinical level are remembered on the device and browser you are using.
Booking a shift

How to book

  1. Select the start date.
  2. Select a start time.
  3. Select a finish time.
  4. Select a flexibility restriction if applicable: N, A, B, or C.
  5. Check the booking summary shown below the form.
  6. Select Confirm shift.

The system checks that:

  • The shift does not start in the past.
  • You do not have another overlapping booking.
  • No more than three people are booked at one time.
  • Only one REC observer is booked per hourly period.
A REC booking occupies one of the three available places but is an observer and does not count toward operational crew coverage.
Understanding the Timeline

Roster-day time period

Roster days run from:

08:00 until 07:59 the following morning.

For example, a booking at 03:00 Tuesday appears under the roster-day card for Monday.

Coverage colours

Red
No operational crew are assigned.
Yellow
One operational crew member is assigned.
Green
Two or more operational crew are assigned.

Expanding and collapsing days

Select a day heading to show or hide its hourly timeline. Use Expand all or Collapse all to manage all visible days at once.

Viewing the printable team roster

Team roster view

Select:

📋 View Team Roster — Next 14 Days

This opens a separate window containing a roster table. In that window you can:

  • Select a different date range.
  • Move to the next 14-day period.
  • Print the displayed roster.
  • Close the roster window when finished.
Booking list, My bookings, and cancellations

Booking list

Select the Booking list tab to view active bookings for the team.

Use the search field to find a booking by crew member, clinical level, flexibility code, or date.

My bookings

Select My bookings to view upcoming bookings matching the name entered in the header.

Use your name consistently. A different spelling, nickname, or extra space may prevent your bookings from appearing in My bookings.

Cancelling a shift

  1. Find the booking in the Booking list or My bookings.
  2. Select Cancel.
  3. Read the confirmation message and confirm the cancellation.
Team messages

Shared roster messages

Select Team messages to view or post notes visible to other users of the same team roster.

Use the message board for:

  • Availability updates.
  • Leave notifications.
  • Roster-related information.
  • General team coordination.

Posting a message

  1. Make sure your name is entered in the header.
  2. Open Team messages.
  3. Type your message.
  4. Select Post message.

Deleting a message

  • A message posted from your current browser will show a Delete button.
  • A roster manager can remove any message using Manager delete and the manager password.
  • If browser data is cleared or you use another device, your normal Delete button may no longer be available.
Do not post confidential information. Never include patient details, clinical details, private contact information, or other sensitive personal information.
Submitted hard-copy roster periods

Hard-copy submission status

The roster displays whether a hard-copy roster period has been submitted to Country Rostering.

Bookings and cancellations are still allowed during a submitted period. However, changes that overlap that period require notification to Country Rostering.

If the roster displays a Country Rostering warning, follow the on-screen prompt after making the booking or cancellation.

Country Rostering phone number:

1300 850 985

Refreshing and getting help

Refresh the roster

Select Refresh roster to load the latest bookings and hard-copy submission status.

Refresh the roster if:

  • You have left the page open for some time.
  • A booking or cancellation was unsuccessful.
  • You need to see another person’s recent booking.
  • The page shows a connection or verification warning.

If something is not working

  1. Check your internet connection.
  2. Select Refresh roster.
  3. Check that your name and clinical level are correct.
  4. Try refreshing the browser page.
  5. Contact your roster manager if the problem continues.
