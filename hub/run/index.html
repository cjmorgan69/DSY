How to run a DSY session

Written by DSY as a suggested shape for a training night. Adjust it to your group.

Before the night

  1. Pick a topic below and read the facilitator walk-through, including the debrief.
  2. If the topic can be customised, set your own town, station, hospital and times.
  3. Load the MDT job on the iPad and check the setup screen.
  4. Send the students the Learn link so they can do the microlearning first.

On the night

  1. Page out: hand a pair the iPad. They log on, acknowledge and go en route, and talk through their plan while the live remarks arrive.
  2. On scene: run the walk-through with its break points, skills practice and decisions.
  3. Transport: back to the MDT to choose the hospital, go mobile, arrive and clear.
  4. Debrief: use the scenario's debrief points and the MDT run log (times, remarks read, hospital chosen).

After

  1. Log the session in the training app.
  2. Send the student links so the crew can revisit the call on their own.

Training resource only. It does not replace the SAAS protocols or advice from the EOC Clinician.
