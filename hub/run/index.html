How to run a DSY session

Written by DSY as a suggested shape for a training night. Adjust it to your group.

Before the night

  1. Pick a topic below and read the facilitator walk-through, including the debrief.
  2. If the topic can be customised, set your own town, station, hospital and times.
  3. Load the MDT job on the iPad and check the setup screen.
  4. If the topic has skills stations, decide whether to run them before the walk-through or after it.
  5. Send the students the Learn link so they can do the microlearning first.

On the night

  1. Skills stations (optional, before): if the topic has them, run the stations first to warm up the hands-on skills. The team can run them without you.
  2. Page out: hand a pair the iPad. They log on, acknowledge and go en route, and talk through their plan while the live remarks arrive.
  3. On scene: run the walk-through with its break points, skills practice and decisions.
  4. Transport: back to the MDT to choose the hospital, go mobile, arrive and clear.
  5. Debrief: use the scenario's debrief points and the MDT run log (times, remarks read, hospital chosen).
  6. PCR trainer: after the scenario, each student writes the patient care record for the job, then compares it with the model card.
  7. Skills stations (optional, after): if you did not run them first, run them now to practise what came up in the scenario.

After

  1. Log the session in the Session planner.
  2. Send the student link so the crew can revisit the topic on their own.
